# 免费搜索链协议（Search Chain）

> 面向任何 AI coding agent / 脚本 / 终端的联网搜索约定：**自托管免费层 → 免费兜底 → 停车**，全程可审计、绝不静默降级到付费或平台原生搜索。版本 v1.0。
>
> **协议家族**：[devlog](devlog.md) 记过程 · [journal / handoff](journal-handoff.md) 记日常与交接 · [registry](registry.md) 记环境资产 · [skills](skills.md) 管能力资产 · [iron-rules](iron-rules.md) 管行为约束 · **search-chain 管联网获取**。

## 1. 三层结构

```
① q CLI（免费主力，tools/q/q.py）
     后端：自托管 SearXNG（deploy/ 一把起，绑 127.0.0.1）
     容器未跑时自动 docker start（--no-start 可关）
② 免费兜底：国内资讯站 HTML 直抓（httpx/requests 级，无浏览器依赖）
     实证优选：搜狗资讯 div.vrwrap（无验证码）
🚫 停车（STOP）：①② 全挂 → 立即停止 → 报告原因 → 等授权
     绝不私自降级到付费 API 或平台原生搜索硬推进
```

## 2. q CLI 速查

```bash
q "查询词" [-n 5] [--json] [--probe] [--sogou-only] [--no-start] [--timeout 20]
```

- 环境变量：`Q_SEARXNG_URL`（默认 `http://127.0.0.1:8080`）/ `Q_SEARXNG_CONTAINER`（默认 `searxng`，置空禁用自动拉起）/ `Q_LANG`（默认 `zh-CN`）
- 退出码：`0` 成功 / `1` 探针失败 / `2` 停车
- 每次输出尾行盖章：`[搜索:q/<backend> | <cost>]` —— 汇报时原样带进报告执行元信息区

## 3. 节流纪律（批量场景必须）

上游公共引擎有节流墙，批量搜索（巡检/批量调研）必须：

1. **≤4 个主题/批，批间隔 75-120s**；
2. **跨任务也要 ≥90s**（两个搜索任务隔几秒 ≈ 变相连发，照样撞墙）；
3. 连续 2 批全 0 结果 → **早退止损**，不要硬刷；
4. 恢复前先跑 `q --probe`（week 档 >0 才算真恢复）。

## 4. 「200 但 0 条」双故障判别

| 症状（看后端日志） | 病因 | 处置 |
|---|---|---|
| CAPTCHA / 429 / unusual traffic | 上游节流墙 | 静默 ≥30 分钟自愈，**等** |
| 全引擎 ConnectTimeout | 容器出网断 | 查宿主网络/代理是否开启 |

## 5. 反模式

- **静默换付费/原生搜索**：免费层挂了不报告就切付费通道——本协议唯一红线
- **无盖章**：搜索结果不带 `[搜索:… | …]` 标注，事后无法审计成本与来源
- **无间隔连发**：把「能调通」当「可以随便调」，节流墙教你做人
