# Freshness Gate（知识时效闸）

> **一句话**：不问模型「你截止到哪天」（答不准）；把「现在几点 / 什么事会变 / 这实体存在吗」外置成一段跨平台一致的规则来决定**查不查**，查完强制带「截至日期 + 版本号 + 可点开 URL」三要素。
> 粘贴版见 [`snippets/AGENTS-freshness.md`](../snippets/AGENTS-freshness.md)；与 [registry.md](registry.md)（先查本地登记）和 [search-chain.md](search-chain.md)（免费链 + 停车纪律）配套。

## 为什么：三个 Gap

LLM 的知识时效问题不是一个「要不要联网」的开关，是三个独立的 gap，混在一起必然漏查或乱查：

| Gap | 是什么 | 典型症状 |
|---|---|---|
| **G1 时间差** | 模型 cutoff 落后于现实，且模型自报 cutoff 不可靠 | 「最新版本」实为半年前；自信满满地报出早已废弃的 API |
| **G2 实体缺失** | cutoff 之后出现的新实体，模型没见过 | 编造该实体的功能描述（幻觉最危险区） |
| **G3 版本漂移** | 实体存在但版本/API 已变 | 陈旧断言：旧参数名、旧配置法、已移除的默认值 |

## 知识时效闸

你的参数知识有截止日，用户做的是新工程（新模型/新框架/新库新版本）。

- **必查三类**：① 显式要新（最新/现在/今年/release/changelog）；② 版本或 API 断言（怎么装/怎么配/兼不兼容）；③ 陌生专名——判据：说不出它何时首次出现、官方站点在哪，即按陌生处理。认识"家族"≠认识"型号"（认识 YOLO ≠ 认识它的最新一代）。
- **不必查**：稳定知识（数学/算法/协议/历史）；用户已给权威来源或指定版本。例："解释 IoU"不查；"用最新一代 YOLO 训练模型"必查。
- **查法**：**先本地后外网**——判陌生后先查本系统已注册的工具链与登记表（本地资产名外网搜不到是常态，外网空结果回查本地），确认非本地资产再外网检索。检索通道用本平台已约定的（付费须先说明理由并获准）；源序：官方 > 发布页/包注册表 > 论文 > 社区 > 媒体。
- **答法即自检**：写下每个版本号/发布日期的同时落来源标记——查过的内联「截至 YYYY-MM-DD，vX.Y.Z，URL」；没查的紧跟「（记忆，未核实）」。发现裸版本号（无来源无标记）：去查，或补标"未核实"。

## 判定序（便宜 → 贵）

决定「这一处要不要联网核验」时，按成本从低到高过：

1. **词法（S0/S1）**：显式要新词触发；版本号断言触发。注意：裸年份不触发（「2018 年提出的 Transformer」是历史陈述不是时效问题）。
2. **实体探针（S3，可选层）**：对新实体先打一次包注册表/官方 API 的存在性探针——latest > 请求版本、请求版本不存在、探针 404 → 必查；latest == 请求版本 → 直接以探针结果作答（自带三要素）。
3. **本地索引（S2）**：查你的环境注册表（[registry.md](registry.md)）——本地已登记的资产以登记为准。
4. **模型自评（S4）**：只触发不采信——模型说「我知道」不构成免查理由。
5. **检索后置校验（S5）**：查完的断言回检是否覆盖了原文的关键限定（版本号/平台/前提条件）。

## 评估集骨架（可复现评测）

想量化你的 agent 时效纪律，用这套骨架（24 题，每题 ×3 次取多数）：

| 类 | 题量 | 考什么 |
|---|---|---|
| A post-cutoff 实体 | 6 | 2 真新（应查出）/ 2 编造实体（期望「未核实」，**严禁编描述**）/ 2 家族陷阱（认识家族≠认识型号） |
| B 版本变更 | 6 | 2 陈旧断言陷阱 / 2 当前版本配置 / 1 超前版本 / 1 两版本间 breaking change |
| C 稳定知识 | 6 | 4 纯概念 / 2 回望日期负例（不应触发查询） |
| D 环境相关 | 6 | 本地可探测（期望零外网请求） |

四条纪律：①任一题 3 次全漏 = 系统性漏查；伪造引用出现任何一次即不通过；②题库月度换血（A 类槽位从包注册表新 release 生成，ground truth 取当日快照）；③机械评分（正则扫裸版本号 + URL HEAD 验真）；④漏查归因——判定层失误改规则卡，执行层失误改输出强制。

| 指标 | 目标 |
|---|---|
| 漏查率（该查没查） | 0 |
| 误查率（不必查却查） | ≤10% |
| 陈旧率（含已被取代的版本/API） | ≤5% |
| 引用完整率（日期+版本+URL） | 100% |
| 引用真实率（URL 可解析且支持断言） | 100%（零容忍伪造） |
