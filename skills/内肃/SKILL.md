# Skill: 内肃 🔴

> 系统级 · 全系统扫除。低频重型操作，**有破坏性**（全库扫描/归档/删除）。日常会话级卫生（整理/收工/代码清洗/评审/规范审查）见 [整理](../整理/SKILL.md)。

<HARD-GATE>
1. **仅限用户显式触发**——agent 永不自动发起任何档位的内肃。
2. **备份前置**——涉及归档/删除的目标，先备份（`_backups/` 带日期目录）后动手；零删除原则优先（能归档不删除）。
3. **开场声明**——执行前报告预算（预计时长）与影响范围（将扫描/触碰哪些目录），用户确认后进入。
</HARD-GATE>

## N1: 全量代码肃清（代码层面全量，逐项销项）

> 逐项体检：每步执行完输出状态（✅/⚠️/🔴 + 发现数）→ 用户确认 → 继续。

- [ ] N1.1 代码质量扫描（每项目 lint + 行数，输出错误数 + 上帝文件清单）
- [ ] N1.2 上帝文件拆分（匹配 [整理](../整理/SKILL.md) L3.3 拆分模式库，方案确认后执行）
- [ ] N1.3 安全审计（无硬编码凭据 / .gitignore 排除凭据文件 / .env 不入 git）
- [ ] N1.4 大文件排查（>10M 文件：在 .gitignore？无嵌入式 .git？无临时残留？）
- [ ] N1.5 服务健康检查（正向：活跃服务正常；反向：僵尸服务；定时任务引用已停用项告警。平台感知）
- [ ] N1.6 CHANGELOG 对齐 + 遗漏扫描（git log 近期 commit 是否已记录；对照任务队列找漏记事项）
- [ ] N1.7 三层知识对齐（记忆层过期事实 / agent 配置层 / 人类文档层 README）
- [ ] N1.8 计划归档（已完成计划 → `plans/archive/`，更新任务队列）
- [ ] N1.9 汇总报告 + 经验结晶（扫 journal 近 7 天 + 踩坑记录新增，提取可复用模式）+ 技能活跃度统计（30 天零触发的技能标记 ⚠️）

## N2: 全系统大扫除（系统层面，N1 全跑后进入）

- [ ] N2.1 目录结构审查（空目录 / 嵌套>4 层 / 散落文件 / 命名规范一致性）
- [ ] N2.2 文件命名规范（中英混用 / 日期格式不一 / 空格特殊字符 / `_` 前缀语义）
- [ ] N2.3 无效文件识别（空文件 / 重复 / *.tmp·bak·swp 残留 / >30 天过期备份）
- [ ] N2.4 索引与配置自清理（索引引用文件是否存在 / 交叉引用断链 / 过时注释）
- [ ] N2.5 内容归档整理（已完成计划归档 / 过时文档转移 / 碎片目录合并；**溯源优先**：归档前确认有溯源记录，归档后更新索引）
- [ ] N2.6 多工作区/多节点结构一致性（如有：目录结构对比）
- [ ] N2.7 项目健康检查（**按顺序**：①初心对齐检测——对照工作区核心原则（如「原创吸收/减少依赖/改动可溯源」），未登记的新依赖即 🔴 ②开发偏移检测 ③计划完成度 ④CHANGELOG 遗漏挖掘 ⑤方向评估）→ 写入任务队列 + CHANGELOG

## N3: 月度盘点（轻量月度收口，~2h，不深挖）

> 与 N2 的边界：N2 是季度/里程碑级深挖；N3 是月度增量收口。当月已有等价盘点产物则跳过对应步。

- [ ] N3.1 信息源月度盘点（订阅源/关注源采集 + 与上期基准对账 + 新增项快裁（四判据：关联/新颖/可操作/社区验证）+ 盘点报告；无信源体系则跳过）
- [ ] N3.2 台账滚动更新（**先备份旧版再写新版**；免费 API 配额富余才补元数据）
- [ ] N3.3 队列轻内肃（任务队列划线清点 + CHANGELOG 遗漏扫描轻量版 + 当月新增文件断链抽查）
- [ ] N3.4 结晶与台账（journal 当月回顾 + 技能活跃度 + 成本对账——当月 API/订阅花费盘点，越线项告警、免费配额消耗记录；台账入 CHANGELOG）
- [ ] N3.5 registry 月度审查（三项）：① 扩展注册账本全表审查（过期依赖/可用替代/长期未启用；审毕回写表头「上次月度审查」日期）② 吸收对照表对账（与全仓 `[溯源:]` 标注抽查一致性）③ 行为禁令月度复盘（grep 当月 journal 的 CoT 标记行 → 失败模式频次排行 → 对 [AGENTS-cot](../../snippets/AGENTS-cot.md) 的版本化**建议**，只建议不擅改）

## 规则

- 报告必须包含**前后对比**
- 安全问题发现后立即警告，不等汇总
- 每步独立可执行，失败不阻塞后续
- 修改前 `git stash` 保护未提交变更
- **溯源优先**：归档/删除前确认有溯源记录（CHANGELOG / journal / index）
- 产物不覆盖旧版（备份留存）
