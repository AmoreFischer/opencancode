# 外部 API 注册表模板

> 复制到工作区 `registry/apis.md`，每行登记一个外部 API（非模型）。模型 API 入 `models.md`，出网代理入 `proxy.md`，自己运行的端点入 `services.md`。规则见 [rules/registry.md](../rules/registry.md)。

| 别名 | 提供商 | 端点 | 凭据位置 | 用途 | 计费 | 状态 | 更新日期 |
|---|---|---|---|---|---|---|---|
| `<alias>` | `<provider>` | `<base-url 或入口>` | `<env 变量名 / 配置路径——绝不写密钥本身>` | `<OCR / 生图 / 推送 / 天气…>` | `<免费 / 按量 / 订阅>` | `活跃` | `<YYYY-MM-DD>` |

**填写要点**

- 凡是有配额、有账单、或一挂就疼的外部 API，一行一个。
- **凭据只写位置**：环境变量名或配置文件路径，绝不写密钥本身。
- 计费形态（`免费` / `按量` / `订阅`）写明——只看这张表就能做成本审计。
- 停用不删行：状态改 `停用`，注明替代者。
