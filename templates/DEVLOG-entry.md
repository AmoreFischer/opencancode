# DEVLOG 条目模板

> 复制以下结构到项目 `DEVLOG.md` 顶部（倒序追加：最新在最上）。`< >` 为占位符，规则见 [rules/devlog.md](../rules/devlog.md)。

```markdown
## #<序号> · <YYYY-MM-DD> · <主题一句话>

**执行元信息**：
- **平台**：<agent 运行的平台 / 界面>
- **会话**：<session-id>
- **模型**：<model-name>（thinking: <high / medium / …>）
- **模式**：<本次工作模式，一句话>
- **花费**：<订阅内 / 免费 / 计费额度>
- **接力点**：基于 #<前条目标识>（首发条目写「新项目启动」）

**做了什么**
- <产出与关键动作>

**决策**
- <决策 + 一句理由>

**踩坑**
- <现象 → 根因 → 解法 / 规避>

**产物**
- <文件 / 文档 / 提交标识>
```
