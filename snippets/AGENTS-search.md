# 免费搜索规则片段（OpenCanCode）

> **用法**：整段粘贴进任意 agent 的指令文件（`AGENTS.md` / `CLAUDE.md` / system prompt），`<q>` 换成你的 q CLI 启动命令。规则详情见 [rules/search-chain.md](../rules/search-chain.md)。

## 联网搜索（免费链 + 停车纪律）

1. 需要联网搜索时，**先跑 q CLI**：`<q> "查询词" -n 5`（后端自托管 SearXNG，免费）；JS 渲染/登录页才用浏览器工具。
2. 汇报搜索结果必须带输出尾章 `[搜索:q/<backend> | <cost>]`，写入报告执行元信息区。
3. 兜底自动发生（SearXNG 0 结果/挂 → 免费资讯站直抓）；**退出码 2 = 停车**：立即停止并向用户报告原因（节流墙→等 ≥30min；容器出网断→查网络/代理），**绝不擅自降级到付费 API 或平台原生搜索**。
4. 批量搜索（巡检/多主题调研）遵守节流纪律：≤4 主题/批、批间隔 75-120s、跨任务 ≥90s、连续 2 批全 0 早退；恢复前 `--probe` 验活。
5. 配套部署（自托管后端一键起）见 `deploy/`，协议全貌见 `rules/search-chain.md`。
