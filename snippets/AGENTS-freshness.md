# 知识时效闸规则片段（OpenCanCode）

> **用法**：整段粘贴进任意 agent 的指令文件（`AGENTS.md` / `CLAUDE.md` / system prompt）。锚点区间（`FRESH:BEGIN/END`）内不含任何工具名/路径/平台专有概念，跨平台逐字一致；后续修订只改 [rules/freshness-gate.md](../rules/freshness-gate.md) 再重粘。配套：环境资产先查 [AGENTS-registry.md](AGENTS-registry.md)，联网检索走 [AGENTS-search.md](AGENTS-search.md)。

## 知识时效闸

你的参数知识有截止日，用户做的是新工程（新模型/新框架/新库新版本）。

- **必查三类**：① 显式要新（最新/现在/今年/release/changelog）；② 版本或 API 断言（怎么装/怎么配/兼不兼容）；③ 陌生专名——判据：说不出它何时首次出现、官方站点在哪，即按陌生处理。认识"家族"≠认识"型号"（认识 YOLO ≠ 认识它的最新一代）。
- **不必查**：稳定知识（数学/算法/协议/历史）；用户已给权威来源或指定版本。例："解释 IoU"不查；"用最新一代 YOLO 训练模型"必查。
- **查法**：**先本地后外网**——判陌生后先查本系统已注册的工具链与登记表（本地资产名外网搜不到是常态，外网空结果回查本地），确认非本地资产再外网检索。检索通道用本平台已约定的（付费须先说明理由并获准）；源序：官方 > 发布页/包注册表 > 论文 > 社区 > 媒体。
- **答法即自检**：写下每个版本号/发布日期的同时落来源标记——查过的内联「截至 YYYY-MM-DD，vX.Y.Z，URL」；没查的紧跟「（记忆，未核实）」。发现裸版本号（无来源无标记）：去查，或补标"未核实"。
