# 开发日志规则片段（OpenCanCode）

> **用法**：整段粘贴进任意 agent 的指令文件（`AGENTS.md` / `CLAUDE.md` / system prompt），把 `journal/` 换成你的工作区日志目录即可。规则详情见 [rules/](../rules/)。

## 开发日志（DEVLOG / Journal / Handoff）

1. 每个项目维护 `DEVLOG.md`：**倒序追加**（最新在最上），一天一节，每节含：做了什么 / 决策 / 踩坑 / 产物。
2. 每条新条目**必须**以「执行元信息」块开头：平台、会话 id、模型（含思考档 / 推理档）、模式、花费、接力点。缺元信息的条目视为不合规，补全后才能收工。
3. 跨模型 / 跨运行时接力的条目，必须注明 **基于 #<前条目标识>**；写之前先对账——若基线已被推进，先核对差异再写，**绝不直接覆盖**（乐观锁思想）。
4. 每日工作记录写 `journal/YYYY-MM-DD.md`；会话结束前更新 `journal/_handoff.md`（< 100 行：会话目标 / 已完成 / 未完成 / 上下文快照 / 下次第一步），供任何后续会话无缝续接。
5. 多个 agent 共用同一 journal 时，每条记录加 `[<agent-名>]` 前缀。
6. 任何密钥 / token 写入日志前必须脱敏。
